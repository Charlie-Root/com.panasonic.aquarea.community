Control your Panasonic Aquarea air/water heat pump from Homey via the Aquarea Smart Cloud service. This community app supports temperature monitoring, setpoint control, mode selection (Auto/Heat/Cool/Off), and automatic device discovery.

This is an unofficial community project, not affiliated with or endorsed by Panasonic. It uses an undocumented private API that may change at any time. Use at your own risk. For best results, use a dedicated secondary Panasonic account for Homey to avoid session conflicts with the official mobile app.
