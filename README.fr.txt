Pilotez votre pompe à chaleur Panasonic Aquarea air/eau depuis Homey via le service Aquarea Smart Cloud. Cette application communautaire permet la surveillance des températures, le réglage des consignes, la sélection du mode (Auto/Chauffe/Froid/Arrêt) et la découverte automatique des appareils.

Il s'agit d'un projet communautaire non officiel, sans affiliation ni approbation de Panasonic. L'application utilise une API privée non documentée susceptible de changer à tout moment. Utilisation aux risques de l'utilisateur. Pour éviter les conflits de session avec l'application mobile officielle, il est fortement recommandé d'utiliser un compte Panasonic secondaire dédié à Homey.
